Setup takes a few minutes and happens on the computer your child uses.

{{% steps %}}

### Install the extension

Open [Aegis Explorer on the Chrome Web Store](https://chromewebstore.google.com/detail/aaepaimdjblkleipgbkgmokokdmdhpob) in Google Chrome and click **Add to Chrome**, then **Add extension**.

Filtering starts right away, with all categories turned on.

### Create an admin password

After installing, a new tab opens asking you to **Create an admin password to protect your filter settings.** Enter a password, confirm it, and click **Set Password**.

Choose something your child won't guess. Anyone with this password can change or loosen the filters.

{{< callout type="warning" >}}
  There is no password recovery. If you forget it, you'll need to remove and reinstall the extension, which resets all settings and logs.
{{< /callout >}}

### Choose an age preset

Sign in with your new password to open the settings page. On the **Blocking** tab, pick the preset closest to your child's age, or **Custom** to choose categories yourself. See [Filtering settings](../filtering/) for what each preset blocks.

### Allow it in Incognito windows

Chrome turns extensions off in Incognito windows unless you allow them. To keep filtering on there too:

1. Go to `chrome://extensions`.
2. Find **Aegis Explorer** and click **Details**.
3. Turn on **Allow in Incognito**.

### Pin the extension (optional)

Click the puzzle-piece icon in Chrome's toolbar and pin Aegis Explorer. Its toolbar icon is the quickest way back to the settings.

{{% /steps %}}

## Getting back to the settings

Click the Aegis Explorer icon in Chrome's toolbar and choose **Open Options**, or right-click the icon and choose **Options**. Enter your admin password to continue.

{{< screenshot src="/images/barrier.png" alt="The Aegis Explorer password screen, asking for the password to access settings." width="1920" height="1200" >}}

When you're done, click **Logout** in the sidebar so the settings can't be changed without the password.
